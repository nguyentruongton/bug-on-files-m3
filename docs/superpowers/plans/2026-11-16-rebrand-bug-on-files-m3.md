# Rebrand to Bug On Files M3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebrand the app to **Bug On Files M3** (short name **Files M3**; **Bất Ổn Files M3** in `README.md`), generate transparent-background icons and a Tauri v2 native logo-only splash screen from `src/assets/bug-on-files-m3.svg`, switch the default M3 theme palette to the logo's navy/sky-blue tones, and rewrite `README.md` with accurate fork attribution and distro-specific build instructions.

**Architecture:** Single-source SVG (`src/assets/bug-on-files-m3.svg`) drives `rsvg-convert` + `tauri icon` for all platform icons, `public/splash.html` for the frameless transparent Tauri splash window, and `AboutDialog` for in-app branding. A lightweight `close_splashscreen` Tauri command coordinates showing `main` only after React mounts, while `themeUtils.ts` updates the default seed color without breaking Matugen overrides.

**Tech Stack:** Tauri v2 (Rust), React 19, TypeScript, Vite 7, Tailwind CSS v4, `@bug-on/m3-expressive`, `@bug-on/m3-fonts`, `rsvg-convert`, `bun test`.

**Spec:** [2026-11-16-rebrand-bug-on-files-m3-design.md](file:///home/stark/Documents/GitHub/material-3-file-explorer/docs/superpowers/specs/2026-11-16-rebrand-bug-on-files-m3-design.md)

## Global Constraints

- Full English app name: `Bug On Files M3` (window title, `productName`, `AboutDialog`).
- Short name: `Files M3` (launcher / `.desktop` entry).
- Vietnamese name `Bất Ổn Files M3` appears **only** in `README.md`; all app UI and metadata remain English.
- App identifier: `com.bugon.filesm3`.
- All generated icons and splash screen must preserve a transparent background (`src/assets/bug-on-files-m3.svg` has `fill="none"` root).
- Splash screen uses Tauri v2 native window (`decorations: false`, `transparent: true`) and displays **only the logo** (no text).
- Do not add the logo to `NavigationRail` or other navigation chrome.
- Default seed color: `#1F305E` (logo Deep Navy); Matugen/Caelestia/GTK dynamic theme overrides must continue to work as before.

## Review Focus

- `close_splashscreen` called when `splashscreen` window is already closed or missing (e.g. hot-reload in `tauri dev`): must still show/focus `main` without panicking or returning an error that blocks startup.
- Running in pure browser/Vite dev mode (`!isTauri()`): `App.tsx` must skip `invoke('close_splashscreen')` cleanly without throwing.
- Generated PNG/ICO/ICNS icons must retain alpha transparency (non-zero transparent border pixels, no white/black opaque background box).
- `AboutDialog` renders the logo with accessible `alt` text and displays `Bug On Files M3` + version without breaking existing `Dialog` layout tests.
- `themeUtils.ts` default `#1F305E` applies when Matugen is disabled or unavailable, while valid Matugen CSS still overrides it when enabled.
